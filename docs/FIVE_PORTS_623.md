# Five forced connections per cut at side 623

**No terminal state on either axis attains deficit 1,062.** In the
west-to-east sweep there is no terminal state even with the deficit
constraint removed:

| axis | first column with empty forward support (zero-based) | possible terminal deficits |
|---|---:|---|
| 1 | 202 | none |
| 2 | 153 | none |

A five-hop cap therefore excludes one-gap equality on this board.
More precisely, if the one-gap upper value is attained, some cut in
`0..202` on axis 1, or `0..153` on axis 2 (whichever chart applies),
must carry **at least six** forced connections. Here cut `i` is east
of column `i`. The test does not exclude such candidates or the
two-gap class. The available bounds are still `129967 ≤ P(623,623) ≤ 129968`.

This test concerns the normalized **one-gap** chart, with the isolate
free and up to five hops on either side of every processed column.
There are 207 tile columns and 621 physical rows in the crop. Both the
hop rows and the two overlapping tile masks at every row of the shared
cut must agree. The full-mask state and class-joining rule are described
in [the absolute-row transfer](ABSOLUTE_PORTS_623.md).

The east-to-west price test takes the union of exact deficit sets at
identical cut states. It drops prices above 1,062; they cannot later
fall because each of the 33 catalogue masks has at most three marks.
For a separate support test, scan west-to-east with every local price
set to zero. An empty frontier in this second test is a geometric
obstruction independent of the equality budget.

The exact-price reverse runs also finished on both axes: on including
column 53 the last offset was lost, with terminal mask `0x0`. Thus
one of cuts `52..205` must carry six or more for a one-gap equality
witness. The west and east tests need not refer to the *same* cut
if several cuts exceed five.

## A side-623 positive control using the fifth port

The subsequent [uncapped seam bound](UNCAPPED_SEAM_TARIFF.md) prices
an arbitrary ordered list and tests the six-or-more case without
discarding larger lists.

On each axis the independently constructed rooted suffix occupying
columns **62–206** passes the full-mask test at its actual total deficit
**868**. Each transition uses its physical cut word and price and must
retain a compatible rooted partition. At least one cut has five
connections. The control is extracted from a physical rooted region,
not generated by the cut-word DP itself. Thus simply discarding the
fifth port would fail this control. At cut 61 the hop rows are
`24,27,30,38,45` and the east-side partition is `(0,0,0,0,1)`.
An independent mark-graph traversal agrees with the partition at
every cut of the control.

This particular suffix leaves price 194 for the rest of the board.
Even if that price constraint is removed, and all isolate offsets are
allowed at the western end of the suffix, its pinned boundary word
and component partition admit no five-hop continuation through column
57. This control on one suffix must not be confused with the test
over all possible suffixes.
